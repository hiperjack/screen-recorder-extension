プライバシーポリシー

最終更新日: 2026年3月15日

「操作手順書ジェネレーター」（以下「本拡張機能」）は、ユーザーのプライバシーを尊重し、個人情報の保護に努めます。

収集するデータ

本拡張機能は、録画機能の使用中に以下のデータをローカルに保存します。

  • 操作対象のページのスクリーンショット画像
  • クリック・入力・選択などの操作情報（要素名、入力テキスト、XPathなど）
  • 操作対象ページのURL・ページタイトル

データの保存場所

すべてのデータはお使いのブラウザ内（chrome.storage.local および chrome.storage.session）にのみ保存されます。外部サーバーへのデータ送信は一切行いません。

データの安全対策

  • パスワード入力欄（type="password"）の内容は記録しません
  • URLに含まれる機密性の高いパラメータ（token、key、secret、session など）は自動的にマスクされます

データの共有

本拡張機能は、ユーザーのデータを第三者に送信、共有、販売することはありません。エクスポート機能（ZIP、PowerPoint）によるファイル出力はすべてユーザーの操作によりローカルに保存されます。

権限の使用目的

  • activeTab / tabs: 録画中のタブ情報の取得およびスクリーンショットの撮影に使用します
  • scripting: 操作記録用のスクリプトをページに注入するために使用します
  • storage / unlimitedStorage: 記録したステップデータや設定をローカルに保存するために使用します
  • host_permissions (<all_urls>): あらゆるウェブページ上で操作を記録できるようにするために使用します

お問い合わせ

本ポリシーに関するご質問は、Chrome Web Store の拡張機能ページよりお問い合わせください。

Privacy Policy

Last updated: March 15, 2026

"Operation Manual Generator" (the "Extension") respects your privacy and is committed to protecting your personal information.

Data Collected

While the recording feature is active, the Extension stores the following data locally:

  • Screenshots of the pages being operated on
  • Interaction data such as clicks, text input, and selections (element names, input text, XPath, etc.)
  • URLs and page titles of the pages being operated on

Data Storage

All data is stored exclusively within your browser (chrome.storage.local and chrome.storage.session). No data is ever transmitted to external servers.

Data Safety Measures

  • Password fields (type="password") are never recorded
  • Sensitive URL parameters (token, key, secret, session, etc.) are automatically masked

Data Sharing

The Extension does not send, share, or sell any user data to third parties. All file exports (ZIP, PowerPoint) are saved locally through user-initiated actions.

Permission Usage

  • activeTab / tabs: Used to access the current tab for screenshots and tab information during recording
  • scripting: Used to inject the recording script into web pages
  • storage / unlimitedStorage: Used to store recorded step data and settings locally
  • host_permissions (<all_urls>): Used to enable recording on any web page

Contact

For questions about this policy, please contact us through the Extension's page on the Chrome Web Store.
