# 操作手順書ジェネレーター — Chrome 拡張機能

画面操作（クリック・入力・ドロップダウン選択）を自動キャプチャし、
スクリーンショット付きの手順書を **HTML + ZIP** で出力します。

---

## インストール方法

1. このフォルダ（`screen-recorder-extension`）を PC 上の任意の場所に配置します。
2. Chrome のアドレスバーに `chrome://extensions` と入力して開きます。
3. 右上の「**デベロッパーモード**」トグルをオンにします。
4. 「**パッケージ化されていない拡張機能を読み込む**」をクリックします。
5. このフォルダを選択します。
6. ツールバーに 📋 アイコンが表示されれば完了です。

---

## 基本的な使い方

| 手順 | 操作 |
|------|------|
| 1 | ツールバーの 📋 アイコンをクリックしてポップアップを開く |
| 2 | **「記録を開始する」** をクリックし、タイトルを入力して OK |
| 3 | キャプチャしたいページを通常通り操作する |
| 4 | 操作が完了したら **「記録を停止する」** をクリック |
| 5 | 自動的に編集モードが開くので内容を確認・編集して **「💾 保存」** |

保存すると `index.html` + `screenshots/` フォルダを含む ZIP ファイルが生成されます。
ファイル名は `{タイトル}_YYYYMMDDHHMM.zip` 形式です。

---

## キャプチャ対象の操作

| 操作 | 詳細 |
|------|------|
| **クリック** | リンク、ボタン、クリック可能な要素（マウスボタンを押した瞬間に記録） |
| **テキスト入力** | input フィールド、テキストエリア（0.8 秒の無入力後に記録）※ パスワードフィールドは除外 |
| **ドロップダウン選択** | `<select>` 要素 |

各ステップには操作対象の要素名・URL・入力値（テキスト入力の場合）・スクリーンショットが自動で記録されます。
UI 言語（日本語 / 英語）に合わせて要素名の表記も切り替わります。

---

## ポップアップの機能

ポップアップは **記録ボタン** と **ページ遷移ボタン** のみのシンプルな構成です。

### 記録ボタン
- **「記録を開始する」** — クリックするとタイトル入力ダイアログが表示される。タイトルを入力して OK を押すと記録開始。
- **「記録を停止する」** — 記録を終了し、自動的に編集モードを開いてステップを読み込む。ステップが 0 件の場合は編集モードを開かない。
- 記録中はステップ数がリアルタイムで表示される。

### ページ遷移ボタン
- **📂 編集** — 編集モード（editor.html）を新しいタブで開く
- **👁 照会** — 照会モード（viewer.html）を新しいタブで開く
- **📑 最終化** — 最終化ページ（finalizer.html）を新しいタブで開く

### 共通
- **言語切り替え** — 右上の `EN` / `日` ボタンで UI を日本語 / 英語に切り替え（全ページ共通）

---

## 📂 編集モード（editor.html）

記録停止後に自動で開くほか、既存の ZIP ファイルをドロップして読み込むことも可能です。

- タイトル・**概要（サマリー）**・操作内容（要素名）・アクション種別・メモの編集
- スクリーンショットの差し替え（ファイル選択 / クリップボード貼り付け / **📸 1枚撮る**）
- ステップの **ドラッグ＆ドロップ** による順序入れ替え・有効 / 無効の切り替え・新規ステップの追加
- **URL 表示** — 出力 HTML に URL を含めるかどうかを切り替え
- **💾 保存** — 保存形式を選択するダイアログが表示され、**ZIP** または **PowerPoint (.pptx)（試験的）** で出力可能（新規は `{タイトル}_YYYYMMDDHHMM.zip`、既存ファイルは元のファイル名）
- **👁 照会** — 照会モードへ遷移（未保存の場合は保存ダイアログを表示）

#### 最終化 ZIP の編集
最終化 ZIP（複数ドキュメント入り）を読み込むと、左サイドバーにドキュメント一覧が表示され、
クリックで切り替えながら各ドキュメントを個別に編集できます。
保存時は元の最終化 ZIP のファイル構成をそのまま保持して上書き保存されます。

#### 📸 1枚撮る機能
ステップのスクリーンショット差し替えボタン「📸 1枚撮る」をクリックすると、
任意のタブに切り替えてクリックするだけでスクリーンショットを取得できます。

---

## 📑 最終化ページ（finalizer.html）

複数の手順書 ZIP をまとめてナビゲーション付きパッケージを作成します。

1. 手順書 ZIP を複数ドロップして追加
2. ナビゲーションのタイトルを入力
3. タイトルの編集・**ドラッグ＆ドロップ** による順序の入れ替えが可能
4. **セクション** を追加して手順書をグループ化（最大 3 階層）
5. 各ドキュメントの「👁」ボタンで照会モードからプレビュー可能
6. **「💾 ナビゲーション ZIP を作成」** をクリックするとひとつの ZIP に統合（ファイル名: `{タイトル}_Navi_YYYYMMDDHHMM.zip`）
7. 展開すると左サイドバーで文書を切り替えられるナビゲーションページ（`index.html`）が生成される

---

## 👁 照会モード（viewer.html）

エクスポート済みの ZIP（単一ドキュメント・最終化ナビゲーション ZIP どちらも対応）を
スタンドアロンビューアーで開きます。

- ZIP ファイルをドロップまたはクリックで選択して表示
- スクリーンショットをクリックすると拡大表示（Esc または画面クリックで閉じる）
- ナビゲーション ZIP の場合、左サイドバーでドキュメントを切り替え可能
- 「✏ エディターで編集」ボタンから編集モードへ直接遷移
- ダーク / ライトテーマの切り替え

## ファイル構成

```
screen-recorder-extension/
├── manifest.json            # 拡張機能の設定
├── background.js            # Service Worker（スクリーンショット取得・状態管理）
├── content.js               # ページに注入されるキャプチャスクリプト
├── i18n.js                  # 日本語 / 英語 UI テキスト定義
├── popup.html               # ポップアップ UI
├── popup.js                 # ポップアップのロジック（記録開始 / 停止）
├── editor.html              # 手順書エディター（フルページ）
├── editor.js                # エディターのロジック
├── finalizer.html           # 最終化ページ（フルページ）
├── finalizer.js             # 最終化のロジック
├── viewer.html              # 照会モード（フルページ）
├── viewer.js                # 照会モードのロジック
├── jszip.min.js             # ZIP 生成・読み込みライブラリ（ローカル）
├── pptxgen.bundle.min.js    # PowerPoint (.pptx) 生成ライブラリ（試験的・ローカル）
├── fonts.css                # ローカルフォント定義
├── fonts/                   # バンドル済みフォント
│   └── NotoSansJP-Variable.woff2
├── icons/                   # 拡張機能アイコン
├── tests/                   # E2E テスト（Playwright）
│   └── extension.spec.js
├── playwright.config.js     # Playwright 設定
└── package.json             # テスト用依存関係
```

---

## テスト

E2E テストには [Playwright](https://playwright.dev/) を使用しています。

```bash
npm install
npx playwright test
```

---

## 注意事項

- `chrome://` ページや Chrome Web Store などの内部ページはキャプチャできません。
- スクリーンショットは PNG 形式で ZIP に同梱されます。
- パスワードフィールド（`type="password"`）の入力値は自動的に除外されます。
- 拡張機能のインストール前に開いていたタブでは、ページを再読み込みするまでキャプチャが有効にならない場合があります。
- フォント（Noto Sans JP）はローカルにバンドルされており、外部 CDN への依存はありません。
