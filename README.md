# 操作手順書ジェネレーター — Chrome 拡張機能

画面操作（クリック・入力・ドロップダウン選択）を自動キャプチャし、
スクリーンショット付きの手順書を **HTML + ZIP** で出力します。

---

## インストール方法

1. このフォルダ（`screen-recorder-extension`）を PC 上の任意の場所に配置します。
2. Chrome のアドレスバーに `chrome://extensions` と入力して開きます。
3. 右上の「**デベロッパーモード**」トグルをオンにします。
4. 「**パッケージ化されていない拡張機能を読み込む**」をクリックします。
5. このフォルダを選択します。
6. ツールバーに 📋 アイコンが表示されれば完了です。

---

## 基本的な使い方

| 手順 | 操作 |
|------|------|
| 1 | ツールバーの 📋 アイコンをクリックしてポップアップを開く |
| 2 | **「記録を開始する」** をクリック |
| 3 | キャプチャしたいページを通常通り操作する |
| 4 | 操作が完了したら **「記録を停止する」** をクリック |
| 5 | タイトルや設定を確認して **「⬇ エクスポート」** をクリック |

エクスポートすると `index.html` + `screenshots/` フォルダを含む ZIP ファイルが保存されます。

---

## キャプチャ対象の操作

| 操作 | 詳細 |
|------|------|
| **クリック** | リンク、ボタン、クリック可能な要素 |
| **テキスト入力** | input フィールド、テキストエリア（0.8 秒の無入力後に記録） |
| **ドロップダウン選択** | `<select>` 要素 |

各ステップには操作対象の要素名・URL・入力値（テキスト入力の場合）・スクリーンショットが自動で記録されます。

---

## ポップアップの機能

### ステップ管理タブ
- **トグル** — 各ステップを出力対象に含めるか個別に On/Off
- **↑ / ↓ ボタン** — ステップの順序を入れ替え
- **操作内容の編集** — 要素名テキストをクリックしてその場で編集
- **メモの追加** — 各ステップに補足コメントを追加（手順書に反映）
- **タイトル** — 出力する手順書のタイトルを設定
- **URL 表示** — 出力 HTML に URL を含めるかどうかを切り替え
- **🗑 クリア** — すべてのステップを削除
- **⬇ エクスポート** — HTML + ZIP を保存

### 📂 読み込み・編集
エクスポート済みの ZIP を新しいタブで開いて再編集できます。

- ZIP またはフォルダを読み込んでステップを表示
- タイトル・操作内容・メモの編集
- スクリーンショットの差し替え・追加・削除
- ステップの順序入れ替え・有効 / 無効の切り替え
- 編集後に新しい ZIP として保存

### 📑 最終化
複数の手順書 ZIP をまとめてナビゲーション付きパッケージを作成します。

1. 手順書 ZIP を複数ドロップして追加
2. タイトルの編集・順序の入れ替えが可能
3. **「ナビゲーション ZIP を作成」** をクリックするとひとつの ZIP に統合
4. 展開すると左サイドバーで文書を切り替えられるナビゲーションページ（`index.html`）が生成される

## ファイル構成

```
screen-recorder-extension/
├── manifest.json      # 拡張機能の設定
├── background.js      # Service Worker（スクリーンショット取得・状態管理）
├── content.js         # ページに注入されるキャプチャスクリプト
├── popup.html         # ポップアップ UI
├── popup.js           # ポップアップのロジックとエクスポート処理
├── editor.html        # 手順書エディター（フルページ）
├── editor.js          # エディターのロジック
├── finalizer.html     # 最終化ページ（フルページ）
├── finalizer.js       # 最終化のロジック
├── jszip.min.js       # ZIP 生成・読み込みライブラリ（ローカル）
└── icons/             # 拡張機能アイコン
```

---

## 注意事項

- `chrome://` ページや Chrome Web Store などの内部ページはキャプチャできません。
- スクリーンショットは Base64 形式で ZIP に同梱されます。
- パスワードフィールド（`type="password"`）の入力値は記録しないことを推奨します。
